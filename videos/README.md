# Videos demo de proyectos

Graba con QuickTime (Grabación de pantalla) un recorrido corto (15-30s) de cada
proyecto y guarda el archivo aquí con EXACTAMENTE este nombre:

- sikua.mp4
- fragancia.mp4
- pame.mp4
- orozco.mp4
- english.mp4

El sitio los detecta automáticamente por el nombre. Si el archivo no existe o
no carga, se muestra el placeholder "Demo próximamente" en su lugar — no hay
riesgo de que se vea roto.

Recomendación: exporta en MP4 (H.264), sin audio, y comprime a menos de ~15MB
por video para que cargue rápido (puedes usar HandBrake o el propio QuickTime
con "Compartir > Guardar como 480p/720p").
