El problema

Quienes buscaban ayuda nutricional llegaban con historias muy distintas — bajar grasa sin perder músculo, controlar diabetes o resistencia a la insulina, o simplemente no saber cómo comer de forma equilibrada — pero se topaban con planes genéricos en papel, sin acompañamiento real ni un camino claro entre "solo quiero un plan" y "quiero resultados más rápidos con entrenamiento supervisado".

La solución

Una landing que arranca validando esas situaciones ("¿te identificas con alguna de estas?") antes de vender nada, presenta dos caminos claros — nutrición sola o nutrición + gimnasio exclusivo — y los lleva a un sistema de reservas real: login/registro, agenda con selección de fecha y hora, y un dashboard de cliente con próxima cita, historial y membresía. Del otro lado, la doctora tiene su propio panel privado para gestionar horarios, bloquear días y llevar la ficha de cada paciente (peso, notas de seguimiento). Beneficios, testimonios y FAQ resuelven las objeciones sin que el usuario tenga que buscarlas.

Mi rol

Diseñé el sitio completo — landing, identidad visual y el sistema de reservas (login, agenda con calendario, dashboard de cliente) — y también el panel privado de administración para la doctora, con gestión de horarios, días bloqueados y ficha de paciente.

Stack y decisiones técnicas

JS vanilla + GSAP para las animaciones, sin el overhead de un framework: es el sitio de una sola profesional, no la complejidad de una plataforma multi-usuario; localStorage para persistir sesión y datos del sistema de reservas sin necesitar backend con base de datos, manteniendo el hosting gratuito.
